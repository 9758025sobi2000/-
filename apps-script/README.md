# 일정 참석 회신 — Google Apps Script 버전

응답자는 **로그인 없이** 링크만 열어 회의·행사·출장 참석 여부를 회신하고,
모든 응답은 행정실 Google 계정의 스프레드시트에 쌓입니다.

| 파일 | 내용 |
|---|---|
| `Code.gs` | 서버 코드 (시트 저장, 관리자 비밀번호 확인) |
| `index.html` | 화면 (참석 응답 / 일정 관리 / 결과 집계) |
| `appsscript.json` | 시간대(Asia/Seoul)와 웹앱 배포 설정. 편집기에 붙여넣을 때는 선택 사항 |

## 설치 (최초 1회, 약 10분)

1. 행정실 Google 계정으로 [Google 스프레드시트](https://sheets.google.com)에서 **빈 스프레드시트**를 만듭니다. 이름 예: `일정 참석 회신`
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 왼쪽 `Code.gs`의 내용을 모두 지우고 이 폴더의 `Code.gs` 내용을 붙여넣습니다.
4. 파일 옆 **＋ → HTML**로 파일을 만들고 이름을 정확히 `index`로 지정한 뒤, 이 폴더의 `index.html` 내용을 붙여넣습니다.
5. 💾 저장합니다.
6. 스프레드시트 탭으로 돌아가 **새로 고침**하면 상단에 **참석 확인** 메뉴가 생깁니다.
   - **참석 확인 → 초기 설정 (시트 만들기)**: 처음 실행할 때 권한 승인 창이 뜹니다. 본인 계정으로 허용합니다.
   - **참석 확인 → 관리자 비밀번호 설정**: 일정 관리·결과 집계에 쓸 비밀번호(8자 이상)를 정합니다.
7. Apps Script 편집기에서 **배포 → 새 배포 → 유형: 웹 앱**을 선택하고 다음처럼 설정한 뒤 **배포**합니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
8. 발급된 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 교원에게 안내합니다.

> 7단계에서 "모든 사용자"가 보이지 않으면 학교 Google Workspace 관리자가 외부 공개 배포를 막아 둔 것입니다. 전산 담당 부서에 허용 여부를 문의하세요.

## 코드를 고친 뒤 반영하기

**배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**를 누르면 같은 URL에 반영됩니다.
"새 배포"를 다시 만들면 URL이 바뀌니 주의하세요.

## 화면과 권한

| 화면 | 이용자 | 기능 |
|---|---|---|
| 참석 응답 | 링크를 받은 누구나 (로그인 불필요) | 인적사항(성명·소속 부서(학과)·구분·보직명·연락처) 저장, 일정별 참석/불참과 의견 제출. 1분마다 새 일정을 자동으로 불러옴 |
| 일정 관리 | 관리자 비밀번호 입력 시 | 일정 등록·수정·회신 마감·삭제 |
| 결과 집계 | 관리자 비밀번호 입력 시 | 일정별 인원, 구분별 참석 수, 응답자 명단, 표 복사, 스프레드시트 바로가기 |

인적사항의 **구분**은 교원 / 직원 / 조교 / 학생 / 외부 / 기타 중에서 고르고, **보직명**은 본인이 직접 입력합니다(없으면 비워 둡니다).

## 스프레드시트 구조

| 시트 | 열 |
|---|---|
| 일정 | ID(자동), 구분, 명칭, 날짜, 시작, 종료, 장소, 회신기한, 안내사항, 마감(Y=수동마감), 등록일시(자동) |
| 응답자 | 응답자키(자동), 성명, 소속 부서(학과), 구분, 보직명, 연락처, 저장일시 |
| 응답 | 일정ID(자동), 응답자키(자동), 일정명, 성명, 소속 부서(학과), 구분, 보직명, 연락처, 응답, 의견, 회신일시 |

### 일정 시트에 직접 입력하기

일정은 웹앱의 **일정 관리** 탭에서 등록하는 것이 기본이지만, `일정` 시트에 직접 한 줄씩 입력해도 됩니다.

- **명칭**과 **날짜**는 꼭 입력합니다. 둘 중 하나라도 비어 있는 행은 앱에 나타나지 않습니다.
- **구분** 칸은 회의 / 행사 / 출장 / 교육 드롭다운에서 고릅니다. 다른 값은 입력되지 않습니다.
- **ID(자동)**와 **등록일시(자동)**는 비워 둡니다. 누군가 웹앱을 열 때 자동으로 채워집니다.
- 날짜는 `2026-11-05`, `2026.11.5`, `2026. 11. 5` 형식, 시간은 `14:00`, `14시`, `오후 2:00` 형식을 모두 읽습니다.
- **회신기한**: 응답을 받는 마지막 날짜입니다. 다음 날부터 자동으로 잠깁니다.
- **마감(Y=수동마감)**: 기한과 관계없이 지금 바로 닫으려면 `Y`를 입력합니다. 이 칸에 날짜를 적으면 회신기한으로 처리합니다.
- 머리글 칸에 마우스를 올리면 각 열의 설명(메모)이 보입니다. 이미 설치한 시트는 **참석 확인 → 초기 설정**을 다시 실행하면 머리글과 메모가 새로 바뀝니다. 입력된 데이터는 지워지지 않습니다.

`응답` 시트는 그대로 참석자 명부로 쓸 수 있습니다(필터·정렬·피벗 테이블 활용).
일정을 삭제해도 그 일정의 기존 회신은 `응답` 시트에 기록으로 남습니다.
시트의 열 순서를 바꾸거나 머리글을 지우면 앱이 동작하지 않으니, 분석은 사본 시트에서 하세요.

## 알아둘 점

- **본인 확인이 없습니다.** 링크를 아는 사람은 누구나, 다른 사람 이름으로도 응답할 수 있습니다. 링크는 소속 구성원에게만 안내하세요.
- **응답자는 브라우저 단위로 구분됩니다.** 같은 브라우저로 다시 열면 이전 응답을 이어서 수정할 수 있지만, 다른 기기나 시크릿 창에서 응답하면 별도 응답자로 한 번 더 기록됩니다. 결과 표에 같은 이름이 두 번 보이면 회신 일시가 늦은 쪽을 기준으로 판단하세요.
- 관리자 비밀번호를 10번 연속 틀리면 10분간 관리자 로그인이 막힙니다. 비밀번호는 언제든 **참석 확인 → 관리자 비밀번호 설정**으로 바꿀 수 있습니다.
- 사용량 한도는 Google 계정 종류에 따라 다릅니다: [Apps Script 할당량](https://developers.google.com/apps-script/guides/services/quotas)
